# Frontend Developer Portfolio (HTML Only)

This is a simple, multi-page website built purely with semantic HTML without any CSS styling. It is designed to practice website architecture, semantic layouts, SEO meta tags, and form structures as part of a frontend learning roadmap.

## 🚀 Features

- **Semantic HTML Structure:** Uses modern semantic tags like `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`.
- **Multi-page Architecture:** Seamless navigation across multiple connected HTML pages.
- **Basic SEO Meta Tags:** Includes proper `<meta>` tags (charset, viewport, description) in the header of each page.
- **Interactive Form:** Includes a semantic contact form with fields for name, email, and message.
- **Accessibility (a11y):** Form labels linked to inputs and structured lists for screen readers.

## 📂 Pages Included

1. **Home (`index.html`):** Overview of the developer, hero section, work experience, education, and teacher reviews.
2. **Projects (`projects.html`):** Detailed list of completed portfolio projects.
3. **Articles (`articles.html`):** Collection of written notes and articles.
4. **Contact (`contact.html`):** Contact page equipped with a fully structured input form.

## 🛠️ Tech Stack

- HTML5

## 💻 How to Run Locally

1. Clone or download this repository.
2. Navigate to the `portofolio-website` folder.
3. Open `index.html` in any web browser (Google Chrome, Firefox, Edge, etc.).
